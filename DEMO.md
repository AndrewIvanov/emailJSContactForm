# Демонстрация проекта для сдачи

**Иванов Андрей Александрович, группа 5-МВ-5.**

Ниже указан порт 8080 по умолчанию. На компьютере, где подготовлен проект, в `.env` выбран `SITE_PORT=18080`, поэтому для записи используйте http://localhost:18080 и покажите проброс порта 18080.

## Сценарий видео на одну минуту

1. Откройте Docker Desktop, терминал в папке проекта и браузер.
2. В терминале выполните `docker compose up --build -d`, затем `docker compose ps`. Покажите запущенный контейнер и порт `8080`.
3. Откройте http://localhost:8080. Покажите форму и оформление страницы.
4. Откройте `public/index.html` в редакторе. Замените `Мы будем рады вашему сообщению.` на `Привет из Nginx в Docker!` и сохраните файл.
5. Обновите страницу в браузере. Покажите изменившуюся надпись. Контейнер при этом не перезапускается.
6. Выполните `docker compose exec web nginx -t`. Покажите успешную проверку конфигурации. После демонстрации верните исходную надпись в HTML.

Сохраните запись под именем `screen.mp4`. Загрузите её вместе с проектом в свой репозиторий, если преподаватель требует видео. Ссылку можно добавить в `REPORT.md`: `[Видео демонстрации](./screen.mp4)`.

## Что объяснить на защите

| Вопрос | Ответ |
| --- | --- |
| Что такое образ? | Шаблон файлов и настроек для запуска контейнера. В проекте он собирается из Dockerfile на основе `nginx:alpine`. |
| Что такое контейнер? | Запущенный экземпляр образа с собственными процессами и файловой системой. |
| Для чего нужен Compose? | Он описывает сборку, порты и подключение файлов, чтобы запускать проект одной командой. |
| Что значит `8080:80`? | Слева порт компьютера, справа порт Nginx внутри контейнера. |
| Почему изменения HTML видны сразу? | В контейнер подключена папка `public/` с компьютера. Nginx читает актуальные файлы, а кэширование отключено. Страницу нужно обновить вручную. |
| Что означает `:ro`? | Подключённые файлы доступны контейнеру только для чтения. На компьютере их можно редактировать. |
| Зачем копировать сайт в образ, если есть bind mount? | Копия позволяет запускать образ отдельно. При запуске через Compose подключённая папка перекрывает эту копию и обеспечивает обновление без сборки. |
| Когда нужен перезапуск? | После изменения `nginx.conf`: `docker compose restart web`. После правки HTML, CSS и JavaScript достаточно обновить страницу. |
| Работает ли отправка писем? | Она требует настройки EmailJS. Сейчас параметры пустые; сайт и проверка полей работают, письма не отправляются. |
| Как остановить проект? | `docker compose down`. Файлы сайта на компьютере сохранятся. |
